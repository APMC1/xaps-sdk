# Copy-paste: XAPS audit gate for agent creators

Add this block to your agent system prompt:

```
Before performing any action that modifies state (e.g., send_transaction, approve, deposit, sign_message):
  1. Check: Does this move value or irreversible state?
  2. If YES → call xaps_audit with action, contract_address, and amount
     - If RECEIPT.status = "APPROVED" → proceed
     - If RECEIPT.status = "REJECTED" → replan or abort
  3. If NO → proceed

If no capability to audit (e.g., missing tool) → search_xaps_registry → delegate via Tollbooth.
```

Register the MCP server from [APMC1/xaps-sdk](https://github.com/APMC1/xaps-sdk) using `xaps_mcp_server.py`.
